# Buddhist 5A Analysis PPT

This repository contains the slide content and a small script to generate a .pptx file locally.

Files:
- slides_content.md — the text content for each slide (use this to create the PPTX)
- generate_pptx.py — a Python script that converts the markdown into a .pptx using python-pptx

How to create the PPTX locally:
1. Clone the repo: git clone https://github.com/shubhh1122/buddhist-5A-analysis-ppt.git
2. Install requirements: pip install python-pptx markdown
3. Run: python generate_pptx.py
4. The script will produce 'Buddhist_5A_Analysis.pptx' in the repository root.

Notes:
- The assistant could not upload directly into Google Drive. This repo is public so you can download and move the generated PPTX to your Drive.
- The slides are dense, formatted for A4 printing. No images are included per your request.
